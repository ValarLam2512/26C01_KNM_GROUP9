TOKEN – GROUP 09 | BẢN SỬA LỖI CSS VÀ ẢNH

1. Giải nén TOÀN BỘ file ZIP vào một thư mục mới (ví dụ Desktop\TOKEN_GROUP09).
2. Mở thư mục vừa giải nén. Bạn phải nhìn thấy index.html và thư mục assets nằm CÙNG CẤP.
3. Nhấn đúp index.html để mở bằng Chrome hoặc Edge. KHÔNG kéo riêng index.html ra ngoài thư mục.
4. Giữ nguyên thư mục assets vì CSS, JavaScript và ảnh thành viên được nạp từ đây.

Cấu trúc đúng:
TOKEN_GROUP09/
  index.html
  assets/
    css/token-style.css
    css/layout-fallback.css
    js/token-editor.js
    js/token-main.js
    team/...

Bản này đã sửa đường dẫn tài nguyên thành ./assets/... và bổ sung CSS bố cục dự phòng.
Một số hiệu ứng Bootstrap Icons và font Google cần Internet; CSS chính và ảnh thành viên được lưu cục bộ.
