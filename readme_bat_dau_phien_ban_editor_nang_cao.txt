TOKEN – GROUP 09 | PHIÊN BẢN EDITOR NÂNG CAO

CÁCH MỞ
1. Giải nén toàn bộ ZIP vào một thư mục.
2. Giữ nguyên cấu trúc thư mục, không tách index.html khỏi assets.
3. Mở index.html bằng Chrome hoặc Edge.
4. Internet cần thiết để tải Google Fonts và Bootstrap CDN. CSS bố cục cơ bản nằm local trong assets.

CÔNG CỤ EDITOR
- Bật chỉnh sửa: nhấn trực tiếp vào văn bản để sửa; nhấn ảnh thành viên để chọn ảnh và mở công cụ crop vuông.
- Font chữ: chọn font riêng cho tiêu đề, nội dung, navigation.
- Thiết kế chữ: đổi font/cỡ chữ/màu chữ/màu nền/màu tiêu đề/màu nhấn; định dạng đoạn được chọn bằng đậm/nghiêng/gạch chân/căn lề.
- Quản lý mục: tạo section mới và liên kết mục lớn/mục con trên navigation; xóa section hoặc chỉ bỏ liên kết.
- Quản lý file: tạo thư viện dạng thư mục, thêm nhiều file, preview định dạng trình duyệt hỗ trợ, tải xuống, xóa.
- Sắp xếp: bật chế độ rồi kéo thả section, card thành viên hoặc directory card để đổi vị trí.
- Xuất website: tải index.html đã chỉnh sửa. Giữ nguyên thư mục assets cạnh file này.

LƯU Ý
- Bản nháp được lưu trong localStorage của trình duyệt hiện tại. Xuất website để tạo bản lưu chuyển máy.
- File tải vào thư viện được nhúng vào HTML khi xuất; file lớn làm HTML rất nặng. Công cụ giới hạn mỗi file 18 MB.
- Preview PDF và ảnh hoạt động trong trình duyệt; một số định dạng Office/ZIP không preview trực tiếp được, nhưng có thể tải xuống.
- Crop ảnh thành viên tạo ảnh vuông 900x900, giữ ảnh gốc bên ngoài nếu cần dùng lại.
- Sắp xếp section/card chỉ thay đổi thứ tự hiển thị; không sửa nội dung gốc.
- Nội dung giới thiệu 4 thành viên đã được khôi phục theo đúng nội dung bạn cung cấp; không tự thêm thông tin cá nhân.
- Lớp: 26C01.
- Để website hoạt động công khai trên Internet, cần tải toàn bộ thư mục website lên hosting; mở file cục bộ không tự xuất bản website.
